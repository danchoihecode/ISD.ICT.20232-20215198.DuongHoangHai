DISPLAY

Number of colors supported: 16,777,216 colors
Resolution: 942 x 594 pixels

SCREEN

Location of standard buttons: At the bottom (vertically) and in the middle (horizontally) of the frame
Location of messages: Starting from the top vertically and in the left horizontally of frame down to bottom
Display screen title: Title is located at top of frame in the left
Consistency expression alphanumeric numbers: comma separator thousand while strings consist characters, 
digits, commas, dots, spaces, underscores, and hyphen symbol.

CONTROL

Size of the text: medium size (mostly 24px). Font: Roboto. Color: #000000
Input check process: Should check if it is empty or not. Next, check if the input is in the 
correct format or not
Sequence of moving the focus: There will be no stack frames. Each screen will be separated. 
However, the manual is considered a popup message, as the main screen cannot be operated 
while the manual screen is shown. After opening screen, app will start with splash screen 
and then the first screen (home screen) will appear.

DIRECT INPUT FROM KEYBOARD

There will be no shortcuts.There are back buttons to move back to the previous screen.
Also, there is the close button “X” located at the title bar to the right to close the screen.

ERROR

A message will be given to notify the users what is the problem.
